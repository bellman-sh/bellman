# docs-site

## Overview

docs.bellman.sh: an Astro Starlight site with its own `package.json` and
lockfile, built to static pages in `./dist` and served by an assets-only
Cloudflare Worker with no script. It is a separate npm project from the
repository root; the root reaches into it only to generate the tool reference
(`npm run docs:gen`) and to test the pages.

## Interface

- [`./src/EGM.md`](./src/EGM.md): the content collection and the Markdown pages,
  including the generated tool reference.
- `[astro.config.mjs:site]` `https://docs.bellman.sh`; `[astro.config.mjs:starlight.title]`
  `Bellman`; `[astro.config.mjs:markdown.smartypants]` `false`, so quotes stay
  straight as the tools write them.
- `[astro.config.mjs:sidebar]` five groups: Start (`index` plus autogenerated
  `start`), Guides, Concepts and Help (each autogenerated from its directory), and
  Reference (`Tools` autogenerated from `reference/tools`, then the explicit slugs
  `reference/bridge-tools` and `reference/bellman-command`).
- `[astro.config.mjs:plugins]` `[starlightLinksValidator()]`.
- `[package.json:scripts]` `dev` (`astro dev`) and `build` (`astro build`);
  `[package.json:engines]` node `>=22.22.0`; dependencies `@astrojs/starlight`,
  `astro`, `starlight-links-validator`; devDependency `wrangler`.
- `[wrangler.toml]` Worker `bellman-docs`, `[assets] directory = "./dist"`,
  `not_found_handling = "404-page"`, `[[routes]] pattern = "docs.bellman.sh"`
  with `custom_domain = true`, `workers_dev = false`. No `main`: there is no
  script. `account_id` comes from `CLOUDFLARE_ACCOUNT_ID`.
- `[smoke.sh:base, tries]` `sh ./smoke.sh [base URL]`, default
  `https://docs.bellman.sh`; env `TRIES` (default 30).
- `public/`: `favicon.svg`.

## Invariants

- A broken internal link fails `astro build` (`[astro.config.mjs:plugins]`), and a
  sidebar slug that names no page fails it too (`[astro.config.mjs:sidebar]`), so
  an explicit sidebar entry lands in the same change as its page.
- `[smoke.sh:loop]` `/` and `/reference/tools/bellman_start/` must each answer
  HTTP 200 within `TRIES` attempts, 10 s apart, and `[smoke.sh:final curl]` the
  `bellman_start` page must contain `&lt;role&gt;` (the tag shown as text, not
  markup); otherwise it exits 1.
- `[.github/workflows/docs.yml:build]` the built `bellman_start` page contains
  `&lt;role&gt;`, and the `bellman_send` page contains `kind: "html"` with straight
  quotes and at least three `<br>`.
- `[.github/workflows/docs.yml:on]` the workflow runs on pull requests and on
  pushes to `main` that touch `docs-site/**`, `src/tools/**` or the workflow
  itself; `[.github/workflows/docs.yml:deploy]` deploys only on a push to `main`,
  after `build`, in concurrency group `deploy-docs` without cancelling a running
  deploy, and fails if `CLOUDFLARE_API_TOKEN` or `CLOUDFLARE_ACCOUNT_ID` is empty.
  The root `ci.yml` and `publish.yml` do not build this site.

## Side Effects

- `[package.json:scripts.build]` `astro build` writes `./dist`.
- `[wrangler.toml:assets]` `npx wrangler deploy` uploads `./dist` to the
  `docs.bellman.sh` custom domain.
- `[smoke.sh]` read-only `curl` requests against the given base URL.
- `[.github/workflows/docs.yml:build]` runs `npm ci`, `npm run build`, the `dist`
  checks, then `npx wrangler deploy --dry-run --outdir .wrangler/dry-run`;
  `[.github/workflows/docs.yml:deploy]` runs `npm ci`, `npm run build`,
  `npx wrangler deploy`, then `sh ./smoke.sh https://docs.bellman.sh`.

## Verification

- Run: `npm --prefix docs-site ci && npm --prefix docs-site run build` (fails on a
  broken link or a missing sidebar slug)
- Run: `npm test` from the repository root (the generated reference and the
  pages' wording)
- Run: `sh docs-site/smoke.sh <base URL>` against a deployment
