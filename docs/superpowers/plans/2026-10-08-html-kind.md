# The `html` Kind Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A surface item of kind `html`, inline in `body` or backed by a `text/html` blob, never both, that the server stores and serves exactly as it stores a file: as bytes, never as a page.

**Architecture:** One more member of `SURFACE_KINDS` with two rules in `normalizeSurfaceWrite` (exactly one of `body` and `blob`) and one in `writeSurface` (the blob's stored type is `text/html`), the way `image` has its allowlist rule there. Nothing changes in storage, in the download route (an `html` blob is already an `application/octet-stream` attachment, since only allowlisted images are served inline), in the routes or in the Desktop manifest. The tool's description carries the artifact's contract, because that line is where an agent learns what an artifact may do.

**Tech Stack:** TypeScript, zod, vitest; the server's existing surface and blob code.

**Spec:** `docs/superpowers/specs/2026-10-06-surface-html-artifacts-design.md`, D1 and D5 (the rest is the dash repo's plan). Issue #185; piece 4 of the working surface (#129).

## Global Constraints

- `body` stays under `MAX_SURFACE_BODY_CHARS` (8,000) by the shape that bounds every body; no new bound.
- A blob-backed `html` item names a blob stored as exactly `text/html`; the stored type is the object's, never the writer's claim.
- The download route's rule is unchanged and must stay pinned: anything not an allowlisted image is `application/octet-stream`, `content-disposition: attachment`, `x-content-type-options: nosniff`, `content-security-policy: sandbox`.
- No new tool, so `extension/manifest.json` is untouched; `tests/extension.test.ts` keeps passing.
- Writing: a room holds many members; never "two sessions", "the other session", "counterpart", "the other side"; never "load-bearing" or "worth saying plainly". Commits signed (`git -c commit.gpgsign=true commit -S`), subjects in sentence case.
- `npm run verify` green before every commit.

## Review Focus

1. An `html` item with a `blob` whose stored type is `text/html; charset=utf-8` (a parameterised type): a reasonable writer expects it accepted. Pin: the type check compares the media type before any `;`, lower-cased. (Task 1 test.)
2. A `PUT /rooms/:id/surface/:key` through the HTTP route with `kind: "html"` and a body: the route must accept what the tool accepts, since both call `writeSurface`. (Task 1 test.)
3. An inline `body` that is markup but the kind is `text`: nothing here renders it, and nothing must change; the test that a `text` body is stored verbatim already exists and is not touched.
4. A blob uploaded with a claimed type of `text/html` whose bytes are a PNG: `storedType` keeps a non-image claim as its label, so the item is accepted as `html`; the frame renders whatever the bytes are inside its sandbox, which is the design. No change; stated in the description's contract line as "the bytes are the artifact".
5. The download of an `html` blob fetched by a browser must never render: the existing download-header test is extended with a `text/html` blob so the rule cannot regress silently. (Task 1 test.)

```ts
describe("html items (#185)", () => {
  const PAGE = "<!doctype html><title>demo</title><button onclick=\"this.textContent='hi'\">press</button>";
  const HTML = text(PAGE);

  it("places an inline page in body, and a page from a text/html blob, never both and never neither", async () => {
    const p = await pairUp(h);
    const inline = await write(p, { key: "demo", kind: "html", body: PAGE, title: "Demo" });
    expect(inline.isError, inline.text).toBe(false);
    expect((await rows(p))[0]).toMatchObject({ key: "demo", kind: "html", title: "Demo", body: PAGE, blob: null });
    const audit = (await h.store.auditForOrg(p.creator.identity.orgId!, 50)).at(-1)!;
    expect(audit.detail).toMatchObject({ key: "demo", kind: "html", chars: PAGE.length });

    const id = await stored(p, "text/html", HTML, "demo.html");
    const backed = await write(p, { key: "big", kind: "html", blob: { id } });
    expect(backed.isError, backed.text).toBe(false);
    expect((await rows(p)).find((r) => r.key === "big")).toMatchObject({
      kind: "html", body: null, blob: { id, type: "text/html", name: "demo.html", bytes: HTML.byteLength },
    });

    await refusedWith(p, { key: "both", kind: "html", body: PAGE, blob: { id } }, "not both");
    await refusedWith(p, { key: "neither", kind: "html" }, "needs a body");
  });

  it("accepts a parameterised text/html type and refuses any other stored type, which still places as a file", async () => {
    const p = await pairUp(h);
    const charset = await stored(p, "text/html; charset=utf-8", HTML, "page.html");
    const ok = await write(p, { key: "page", kind: "html", blob: { id: charset } });
    expect(ok.isError, ok.text).toBe(false);

    const md = await stored(p, "text/markdown", text("# notes\n"));
    await refusedWith(p, { key: "notes", kind: "html", blob: { id: md } }, "not text/html");
    const asFile = await write(p, { key: "notes", kind: "file", blob: { id: md } });
    expect(asFile.isError, asFile.text).toBe(false);
  });

  it("holds an inline page to the body bound", async () => {
    const p = await pairUp(h);
    await refusedWith(p, { key: "long", kind: "html", body: "<p>" + "x".repeat(MAX_SURFACE_BODY_CHARS) }, "must be at most 8000 characters");
  });
});
```

```ts
  } else {
    if (v.ends) return refuse("only a connector has ends");
    if (blobBacked) {
      if (!v.blob) return refuse("a file or an image needs blob { id } naming a blob uploaded to this room");
      if (v.body) return refuse("a file or an image has no body; its bytes are the blob's");
    } else if (v.kind === "html") {
      // An artifact is inline or a blob, never both (#185, D1): a hosted connector with no

      if (v.body && v.blob) return refuse("an html item is inline (body) or a blob (blob: { id }), not both");

    } else if (!v.body) {
      return refuse("needs a body");
    }
  }
  if (v.blob && !blobBacked && v.kind !== "html") return refuse("only a file, an image or an html item names a blob");
```
