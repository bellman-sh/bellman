# Bylines Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A public room's creator claims a handle and signs the room. The public page then shows "by @handle", and the creator's seat reads @handle. A handle page lists that person's signed public rooms.

**Architecture:**
- Handles and signatures live in `RegistryDO` under `hn:`, `uh:` and `hs:` keys, so no write spans two objects.
- The public room read looks the byline up once and returns `by: { handle, as }`. The dash swaps `as` for `@handle` wherever it renders a member's public name.
- Three PRs, in three repos: bellman (Part 1), dash (Part 2) and the site (Part 3).

**Tech Stack:** TypeScript, Cloudflare Workers and Durable Objects, vitest. The dash is React with TanStack Router and Testing Library. The site is static HTML.

**Spec:** `docs/superpowers/specs/2026-10-12-bylines-design.md` (approved 2026-10-12).

## Global Constraints

- **Handle format:** 3 to 30 characters of lowercase letters, digits and hyphens. It starts with a letter and does not end with a hyphen: `/^[a-z][a-z0-9-]{1,28}[a-z0-9]$/`. Input is trimmed and lowercased first.
- **Reserved handles:** `bellman`, `admin`, `administrator`, `support`, `help`, `root`, `system`, `staff`, `team`, `host`, `api`, `mcp`, `dash`, `www`, `about`, `settings`, `null`, `undefined`, `anthropic`, `claude`.
- **Registry keys:** `hn:<handle>` → userId, `uh:<userId>` → handle, `hs:<userId>:<sessionId>` → signedAt (ms). Releasing a handle deletes the user's `hs:` keys in the same transaction.
- **Errors:** 400 `handle_invalid`, 400 `handle_reserved`, 409 `handle_taken`, 403 `forbidden` (not the creator), 409 `room_not_public`, 409 `no_handle`.
- **Store methods:** every `BellmanStore` method is async. Both stores implement each new one, and the store contract covers it.
- **No tool or manifest change.** The tool listing must stay byte-identical.
- **The page reads "by @handle"**, never "hosted by". Host names the hosted seat.
- **Writing:** a room holds many members. Never write "two sessions" or "the other session". No phrase from `~/.claude/projects/-Users-mcfearsome-src-github-com-bellman-sh-bellman/memory/banned-phrases.md`.

## Rulings on the spec

- **R1. The handle is read at `GET /account/handle`, not in `GET /account`.** The OAuth router serves `/account`, and it has no store. `/account/handle` goes to a new module, dispatched before that router, beside the preset routes. The paths and errors are the spec's. *Cost if wrong:* the dash makes one extra fetch.
- **R2. The handle page wraps each room's name and purpose as `text`, an untrusted envelope labelled `@handle`.** It does not return bare `room` and `purpose` fields. They are a member's words, and the room's own public read wraps them the same way (CLAUDE.md: peer content is untrusted everywhere). *Cost if wrong:* the dash reads one level deeper.
- **R3. "Closed drops out" in D5 is `sessionStatus(s) === "closed"`.** That is beside `isPublic`, which a closed room still passes until its purge.

## Review Focus

1. Padded or mixed-case input such as `"  Ada "` claims `ada`. Task 3 tests it.
2. A handle in the page URL in another case, such as `/public/handles/ADA`, finds `ada`. Task 5 tests it.
3. Releasing a handle while rooms are signed removes `by` from their public reads at once, and a later handle does not bring it back. Tasks 2 and 5 test it.
4. A signed room that is unpublished drops off the handle page. Task 5 tests it.
5. A member who is not the creator tries to sign: 403, and nothing is written. Task 4 tests it.

```ts
// src/handles.ts
/**
 * A public handle (bylines spec D1): the name a room's creator signs a public room with, in place
 * of their sign-in label, which is an email address for most (ADR 0011). Runtime-free, so the
 * routes and the tests share one rule.
 */
export const HANDLE_PATTERN = /^[a-z][a-z0-9-]{1,28}[a-z0-9]$/;

export const RESERVED_HANDLES: ReadonlySet<string> = new Set([
  "bellman", "admin", "administrator", "support", "help", "root", "system", "staff", "team", "host",
  "api", "mcp", "dash", "www", "about", "settings", "null", "undefined", "anthropic", "claude",
]);

export type HandleCheck =
  | { ok: true; handle: string }
  | { ok: false; error: "handle_invalid" | "handle_reserved"; description: string };

export function checkHandle(raw: unknown): HandleCheck {
  if (typeof raw !== "string") return { ok: false, error: "handle_invalid", description: "handle must be a string" };
  const handle = raw.trim().toLowerCase();
  if (!HANDLE_PATTERN.test(handle)) {
    return {
      ok: false,
      error: "handle_invalid",
      description: "a handle is 3 to 30 characters: lowercase letters, digits and hyphens, starting with a letter and not ending with a hyphen",
    };
  }
  if (RESERVED_HANDLES.has(handle)) return { ok: false, error: "handle_reserved", description: `${handle} is reserved` };
  return { ok: true, handle };
}
```

```ts
  async handleOf(userId: string): Promise<string | undefined> {
    return this.handleByUser.get(userId);
  }

  async userOfHandle(handle: string): Promise<string | undefined> {
    return this.handles.get(handle);
  }

  async claimHandle(userId: string, handle: string): Promise<"claimed" | "taken"> {
    const holder = this.handles.get(handle);
    if (holder !== undefined) return holder === userId ? "claimed" : "taken";
    const old = this.handleByUser.get(userId);
    if (old !== undefined) this.handles.delete(old);
    this.handles.set(handle, userId);
    this.handleByUser.set(userId, handle);
    return "claimed";
  }

  async releaseHandle(userId: string): Promise<void> {
    const handle = this.handleByUser.get(userId);
    if (handle !== undefined) this.handles.delete(handle);
    this.handleByUser.delete(userId);
    this.signatures.delete(userId);
  }

  async signRoom(userId: string, sessionId: string, at: number): Promise<void> {
    const mine = this.signatures.get(userId) ?? new Map<string, number>();
    mine.set(sessionId, at);
    this.signatures.set(userId, mine);
  }

  async unsignRoom(userId: string, sessionId: string): Promise<void> {
    this.signatures.get(userId)?.delete(sessionId);
  }

  async signedRooms(userId: string): Promise<{ sessionId: string; signedAt: number }[]> {
    return [...(this.signatures.get(userId) ?? [])]
      .map(([sessionId, signedAt]) => ({ sessionId, signedAt }))
      .sort((a, b) => b.signedAt - a.signedAt || (a.sessionId < b.sessionId ? -1 : a.sessionId > b.sessionId ? 1 : 0));
  }

  async bylineFor(userId: string, sessionId: string): Promise<string | undefined> {
    const handle = this.handleByUser.get(userId);
    return handle !== undefined && this.signatures.get(userId)?.has(sessionId) ? handle : undefined;
  }
```

```ts
  async handleOf(userId: string): Promise<string | undefined> {
    return this.ctx.storage.get<string>(`uh:${userId}`);
  }

  async userOfHandle(handle: string): Promise<string | undefined> {
    return this.ctx.storage.get<string>(`hn:${handle}`);
  }

  async claimHandle(userId: string, handle: string): Promise<"claimed" | "taken"> {
    return this.ctx.storage.transaction(async (txn) => {
      const holder = await txn.get<string>(`hn:${handle}`);
      if (holder !== undefined) return holder === userId ? "claimed" : "taken";
      const old = await txn.get<string>(`uh:${userId}`);
      if (old !== undefined) await txn.delete(`hn:${old}`);
      await txn.put({ [`hn:${handle}`]: userId, [`uh:${userId}`]: handle });
      return "claimed";
    });
  }

  async releaseHandle(userId: string): Promise<void> {
    await this.ctx.storage.transaction(async (txn) => {
      const handle = await txn.get<string>(`uh:${userId}`);
      const signed = await txn.list({ prefix: `hs:${userId}:` });
      const keys = [`uh:${userId}`, ...signed.keys(), ...(handle === undefined ? [] : [`hn:${handle}`])];
      // A delete takes at most 128 keys.
      for (let i = 0; i < keys.length; i += 128) await txn.delete(keys.slice(i, i + 128));
    });
  }

  async signRoom(userId: string, sessionId: string, at: number): Promise<void> {
    await this.ctx.storage.put(`hs:${userId}:${sessionId}`, at);
  }

  async unsignRoom(userId: string, sessionId: string): Promise<void> {
    await this.ctx.storage.delete(`hs:${userId}:${sessionId}`);
  }

  async signedRooms(userId: string): Promise<{ sessionId: string; signedAt: number }[]> {
    const prefix = `hs:${userId}:`;
    const rows = await this.ctx.storage.list<number>({ prefix });
    return [...rows]
      .map(([key, signedAt]) => ({ sessionId: key.slice(prefix.length), signedAt }))
      .sort((a, b) => b.signedAt - a.signedAt || (a.sessionId < b.sessionId ? -1 : a.sessionId > b.sessionId ? 1 : 0));
  }

  async bylineFor(userId: string, sessionId: string): Promise<string | undefined> {
    const [handle, signed] = await Promise.all([
      this.ctx.storage.get<string>(`uh:${userId}`),
      this.ctx.storage.get<number>(`hs:${userId}:${sessionId}`),
    ]);
    return handle !== undefined && signed !== undefined ? handle : undefined;
  }
```

```ts
// src/http/handles.ts
/**
 * A person's public handle (bylines spec D6): read, claimed or changed, and released, at
 * `/account/handle`. On the preset routes' rules: the same caller, CORS for the panel's origins, the
 * same preflight, and the CSRF check on every write a cookie makes. Here, not in the OAuth router
 * that serves `/account`, because that router has no store (plan ruling R1).
 */
import { checkHandle } from "../handles.js";
import { allowedOrigin, corsHeaders, csrfRefusal, preflightResponse } from "../oauth/browser.js";
import { json, methodNotAllowed, problem, type RoomRouteDeps } from "./rooms.js";

export type HandleRouteDeps = Pick<RoomRouteDeps, "store" | "caller" | "panelOrigins">;

const PATH = "/account/handle";

/** `undefined` for any other path, so the server carries on. */
export async function handleRoutes(request: Request, deps: HandleRouteDeps): Promise<Response | undefined> {
  const url = new URL(request.url);
  const path = url.pathname.replace(/\/+$/, "");
  if (path !== PATH) return undefined;
  const origin = allowedOrigin(request, deps.panelOrigins);
  if (request.method === "OPTIONS") return preflightResponse(origin);
  try {
    const who = await deps.caller(request);
    if (!who) return problem(401, "unauthorized", "sign in, or send a bearer token", origin);
    const userId = who.identity.userId;
    if (request.method === "GET") return json(200, { handle: (await deps.store.handleOf(userId)) ?? null }, origin);
    if (request.method !== "PUT" && request.method !== "DELETE") return methodNotAllowed("GET, PUT, DELETE", origin);
    const refusal = csrfRefusal(request, who.via, origin);
    if (refusal) return refusal;

    if (request.method === "DELETE") {
      await deps.store.releaseHandle(userId);
      return new Response(null, { status: 204, headers: corsHeaders(origin) });
    }

    let body: unknown;
    try {
      body = await request.json();
    } catch {
      body = undefined;
    }
    const raw = typeof body === "object" && body !== null && !Array.isArray(body) ? (body as { handle?: unknown }).handle : undefined;
    const check = checkHandle(raw);
    if (!check.ok) return problem(400, check.error, check.description, origin);
    if ((await deps.store.claimHandle(userId, check.handle)) === "taken") {
      return problem(409, "handle_taken", `${check.handle} belongs to someone else`, origin);
    }
    return json(200, { handle: check.handle }, origin);
  } catch (err) {
    console.error(`${request.method} ${path} failed:`, err);
    return problem(500, "internal", "the request failed on the server; nothing was saved", origin);
  }
}
```

```ts
  const who = await deps.caller(request);
```

```ts
 * each wrapped as the creator's words under the handle (plan ruling R2), never their label.

async function handlePage(raw: string, deps: PublicRouteDeps): Promise<Response> {
  let handle: string;

    return notFound("no such handle");
  }
  const userId = await deps.store.userOfHandle(handle);
  if (userId === undefined) return notFound("no such handle");
  const rooms: unknown[] = [];
  for (const { sessionId, signedAt } of await deps.store.signedRooms(userId)) {
```

```ts
// src/lib/byline.ts
/**
 * A signed public room's byline on the page (bylines spec D4, D7). The Worker names every member by
 * number; the byline says which number is the creator who signed, and the page shows @handle there.
 */
import type { Byline } from "@/lib/api"

export const nameFor = (label: string, by: Byline | null): string => (by && label === by.as ? `@${by.handle}` : label)

/** `value` with every `label` property equal to `by.as` shown as @handle, at any depth, as the Worker's byNumber walks. */
export function relabel<T>(value: T, by: Byline | null): T {
  if (!by) return value
  const walk = (v: unknown): unknown => {
    if (Array.isArray(v)) return v.map(walk)
    if (v === null || typeof v !== "object") return v
    return Object.fromEntries(Object.entries(v).map(([k, x]) => [k, k === "label" && x === by.as ? `@${by.handle}` : walk(x)]))
  }
  return walk(value) as T
}
```

```tsx
/**
 * A person's public handle (bylines spec D7): what they sign public rooms with, in place of their
 * sign-in label. Claiming one publishes nothing until a room is signed.
 */
import { useEffect, useState } from "react"
import { Button } from "@/components/ui/button"
import { deleteHandle, getHandle, putHandle } from "@/lib/api"

export function HandleSection() {
  const [handle, setHandle] = useState<string | null | undefined>(undefined)
  const [draft, setDraft] = useState("")
  const [error, setError] = useState<string | null>(null)
  useEffect(() => {
    let live = true
    void getHandle().then((h) => live && setHandle(h), () => live && setHandle(null))
    return () => {
      live = false
    }

    setError(null)
    void putHandle(draft).then((h) => {
      setHandle(h)
      setDraft("")
    }, fail)
  }
  const release = () => {
    setError(null)
    void deleteHandle().then(() => setHandle(null), fail)
  }
  if (handle === undefined) return null
  return (
    <section className="mt-4 rounded-xl border border-border p-5">
      <h2 className="text-base font-medium">Public handle</h2>

        sign-in label is never shown. Releasing a handle unsigns every room, and someone else can claim it.
      </p>
      {handle ? (
        <div className="mt-4 flex items-center gap-3 text-sm">
          <span className="font-mono">@{handle}</span>
          <Button size="sm" variant="outline" onClick={release}>
            Release handle
          </Button>
        </div>
      ) : null}
      <div className="mt-4 flex items-center gap-2">
        <label htmlFor="public-handle" className="sr-only">
          Public handle
        </label>
```
