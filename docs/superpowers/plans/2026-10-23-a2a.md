# A2A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An A2A client signed in to Bellman can ask a public room something at `POST https://mcp.bellman.sh/a2a` and get back the answer of the room's voice.

**Architecture:** Each question becomes an `outside_question` event in the room's `SessionDO`. Its task row is written in the same transaction. The voice answers with a new `bellman_send` type, `outside_answer`, which moves the task to its next state. Domain logic lives in `src/outside.ts` and runs over the `Store` interface, so `MemoryStore` (Node tests) and `DurableObjectStore` (Worker) both work. The JSON-RPC and SSE layer, written by hand, lives in `src/a2a/` and only translates. The hosted seat takes part through a new wake cause and reports skips back to the room.

**Tech Stack:** TypeScript, Cloudflare Workers + Durable Objects, zod 4, vitest (root `tests/`, Node + `MemoryStore`) and `@cloudflare/vitest-pool-workers` (`worker-tests/`).

**Spec:** `docs/superpowers/specs/2026-10-23-a2a-design.md`. The A2A v1.0 spec captures (method shapes, error codes, enum names) are in `/private/tmp/claude-501/-Users-mcfearsome-src-github-com-bellman-sh-site/0ebd0dca-1fda-437d-84ec-1d73e1b7c9ec/scratchpad/a2a/`. If that directory is gone, use https://a2a-protocol.org/latest/specification/.

## Global Constraints

- Only rooms where `isPublic` (`src/store.ts:82`) holds and that are not `closed` answer. Any other tenant gets the same "not found" error as a nonexistent room.
- Every A2A method needs sign-in through `resolveCaller` (`src/worker.ts:188`). Only the cards are unauthenticated.
- Stranger send limit: `STRANGER_SEND_LIMIT = 6` per `SEND_WINDOW_MS = 60_000` per account per room (`src/send-limit.ts`). Going over returns a JSON-RPC error with `data.retry_after` in seconds.
- Ban and suspension text is copied exactly: `BANNED` ("You can't join this room.") and the existing `SUSPENDED` string.
- Open tasks per caller per room: `MAX_OPEN_OUTSIDE_TASKS = 3`.
- Unanswered lifetime: `OUTSIDE_TASK_TTL_MS = 7 * 24 * 60 * 60_000`, after which the task ends `TASK_STATE_FAILED`.
- Seat silence before the voice passes to members: `SEAT_SILENCE_MS = 10 * 60_000`.
- The seat answers at most `SEAT_OUTSIDE_DAILY_CAP = 20` outside questions per room per UTC day.
- Enum strings are SCREAMING_SNAKE as in v1.0 (`TASK_STATE_WORKING`, `ROLE_AGENT`). Method names are PascalCase.
- Card: `capabilities: {streaming: true, pushNotifications: false, extendedAgentCard: false}`, input and output modes `["text/plain"]`.
- No card, page, README line or error message mentions the hosted seat.
- Caller text is wrapped with `untrusted()` (`src/projections.ts:29`) everywhere it reaches a member, a model or a public read.
- No new runtime dependency unless Task 0 shows `@a2a-js/sdk` runs on Workers *and* 0.3 compat is needed.
- Commit messages are one plain sentence describing the outcome, in the style of `git log`.

## Review Focus

1. **Tenant probing:** a tenant naming a private, unpublished or closed room, or a garbage string, must return the same error as a room that doesn't exist. Otherwise a caller can map private rooms. *(Task 7 test.)*
2. **Room goes private mid-wait:** a blocking `SendMessage` or an open stream must end promptly with the task `TASK_STATE_CANCELED`, not hang until the TTL. *(Task 8 test.)*
3. **Two voices answering at once:** two role holders answering the same question must produce exactly one answer. The second gets "already answered" and writes nothing. *(Task 3 test.)*
4. **Non-text parts:** a message with only file or data parts is refused with the spec's content-type-not-supported error. Text parts are kept and the rest dropped. Nothing is stored for a refused message. *(Task 7 test.)*
5. **Handle changes after asking:** a question's `origin` is fixed when it is asked. Renaming or deleting the handle later doesn't rewrite the log. *(Task 6 test.)*
