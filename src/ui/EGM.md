# ui

## Overview

The server side of the MCP Apps page: the one `ui://` resource, and the `_meta` a tool carries to be rendered
through it. The page itself lives in `ui/` at the repository root; `npm run build:ui` bundles it with Vite and
`scripts/wrap-ui.ts` writes it into `src/ui/assets.ts`.

## Interface

- `APP_RESOURCE_URI = "ui://bellman/app.html"` [src/ui/resource.ts:APP_RESOURCE_URI]
- `APP_MIME_TYPE = "text/html;profile=mcp-app"` [src/ui/resource.ts:APP_MIME_TYPE]
- `APP_UI_META = {ui: {resourceUri}}`, placed in a tool's `_meta` (used by `bellman_start`, `bellman_connect`,
  `bellman_confirm`, `bellman_rooms`, `bellman_surface`) [src/ui/resource.ts:APP_UI_META]
- `registerAppResource(server)`: registers the `"Bellman"` resource, which returns `APP_HTML`
  [src/ui/resource.ts:registerAppResource]
- `assets.ts` (generated, gitignored; header: "GENERATED by scripts/wrap-ui.ts from ui/dist/index.html. Do not
  edit, do not commit."): exports `APP_HTML` and `PACKAGE_VERSION`, imported by `resource.ts` and
  `src/a2a/cards.ts` [src/ui/resource.ts:APP_HTML]

## Invariants

- This is the only registered resource, and registering it turns on the server's `resources` capability; per the
  comment, `tests/tools/surface.test.ts` pins this [src/ui/resource.ts:registerAppResource]
- No `csp` is set: per the comment, the page loads nothing external and reaches data only through the host's
  `tools/call` [src/ui/resource.ts:registerAppResource]
- The MIME type is written out, not imported from `@modelcontextprotocol/ext-apps/server`, because that package
  expects the v2 SDK [src/ui/resource.ts:APP_MIME_TYPE]
- Edit `ui/`, never `assets.ts`; every script that compiles or runs the server runs `build:ui` first (root
  `CLAUDE.md`, `package.json` scripts)

## Side Effects

- `server.registerResource` on the `McpServer`, with `_meta.ui.prefersBorder` true and
  `_meta.ui.permissions.clipboardWrite` requested on the content
  [src/ui/resource.ts:registerAppResource]
